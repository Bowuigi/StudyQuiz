# StudyQuiz

Una aplicación sencilla que se ocupa de agregar y presentar cuestionarios, tarjetas, comparaciones, y otras actividades para el estudio.

## Stack tecnológico

- Typescript
- Preact
- TailwindCSS con DaisyUI

Herramientas de desarrollo:

- Vitest para las pruebas.
- Oxlint para el _linting_.
- Oxfmt para el _formatting_.
- Varios _skills_ para _harnesses_ como OpenCode, Pi, etc.
